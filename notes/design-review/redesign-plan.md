# AML 발표형 사이트 수정 기준

2026-10-09. DEUX와 첨부 논문을 다시 분석하고, Lusion·Igloo·Active Theory·Stripe Radar·Linear·Bruno Simon의 실제 웹 화면을 비교한 뒤 정한 구현 기준이다. 상세 관찰은 `reference-analysis.md`, `visual-references.md`, 논문 근거는 `ack-2026-analysis.md`에 남긴다.

## 이전 구현에서 놓친 것

1. 발표형이라는 말을 화면 비율과 페이지 수로만 해석했다. DEUX는 같은 로봇을 계속 보여주며 카메라·확대·분해로 설명 대상을 바꾼다. 작은 정적 관계도와 문장만 남겨서는 그 느낌을 만들 수 없다.
2. 연구의 이야기가 빠졌다. AP와 탐지 수만 제시하면 왜 시간 조건을 통제했고, 왜 같은 조사량으로 다시 비교했으며, 왜 날짜별 분포를 확인했는지 드러나지 않는다.
3. 문장을 줄이는 작업과 화면을 설계하는 작업을 혼동했다. 여백에는 중심 시각 대상이 있어야 하고, 수치는 크게 보이되 실제 근거를 확인할 수 있어야 한다.

## 시각 방향

금융 거래망을 검정 공간 안의 입체 구조로 보여주는 연구 발표. 로봇 모양을 억지로 옮기지 않고, 계좌와 거래라는 연구 자체의 대상을 사용한다. 같은 계좌 A→B를 전체망에서 확대하고 수취 방향 이웃을 펼친다. 결과에서는 이 구조를 뒤로 물리고 실제 수치를 전면에 둔다.

색: 무대 `#000000`, 본문 `#f2f5f4`, 보조 글 `#a6b5b3`, 핵심 거래 `#64e4cb`, 후경 구조 `#24544e`. 청록은 선택한 거래와 결과 강조에 사용하며 다른 계좌를 자금세탁 계좌로 암시하지 않는다.

글꼴: SUIT Variable 한 가족. 한글 제목 38–48px, 본문 18–21px, 근거 14px 이상(1280×720 설계 기준). 발표의 초점은 제목, 그래프, 짧은 근거 세 단계다.

```
┌────────────────────────────────────────────────────┐
│ 나예진                                    AML · 로봇│
│                                                    │
│ 연구 질문                  동일 거래망의            │
│ 짧은 핵심 문장             확대·분해·시점 변화       │
│ 근거 2~3개                 또는 실제 결과 차트       │
│                                                    │
│                     도해의 의미 / 수치의 평가 조건   │
│ 01 / 07       문제 → 방법 → 결과 → 해석          ← → │
└────────────────────────────────────────────────────┘
```

카드식 그림 상자를 두지 않고 큰 대상의 원근·명암·크롭으로 깊이를 만든다. 자동으로 계속 회전하는 장식, 가짜 점수, 배경 입자, 효과만 있는 버튼은 넣지 않는다. 스크롤과 목차 이동에 응답하는 장면 전환에 움직임을 집중한다.

## 7장 이야기와 장면

| 장 | 전달할 내용 | 시각적 변화 |
|---|---|---|
| 문제 | 드문 자금세탁 거래를 찾는 연구 질문 | 큰 전체 계좌망, 중심 A→B 거래 |
| 입력 | 공통 45차원과 수취 방향 2층 관계 | 같은 노드의 근접 촬영, 입력 이웃 펼침 |
| 평가 원칙 | 시간순 분할·미래 이웃 제외·검증에서 선택 | 과거와 미래를 공간적으로 분리, 시간 경계 표시 |
| 전체 결과 | AP와 모델별 경보 수 | 배경망을 물리고 정확한 네 모델 비교 |
| 동일 조사량 | 같은 864건에서의 탐지 수 | 길이가 같은 예산 막대 안의 탐지 비율 |
| 날짜별 해석 | 소수 거래에 양성이 집중된 분포 이동 | 기간 선택으로 표본·양성률·AP를 함께 갱신 |
| 결론 | 결과와 원인 설명의 구분 | 전체망으로 돌아오며 다음 검증을 제시 |

## 구현과 검수 범위

- 기존 정적 사이트와 탐색기를 재사용한다. AML 전용 스타일과 장면 모듈, 로컬 보관 Three.js·글꼴을 추가한다. 공통 탐색에서는 장면 변경 이벤트만 전달한다. 로봇 실습의 수식·입력은 보존하고 회귀 검증한다.
- 모바일과 좁거나 낮은 창은 흐름형 레이아웃과 2D 구조도를 사용한다. WebGL 모듈은 발표 모드에서만 불러온다. GPU 이용 불가일 때도 2D로 읽을 수 있다.
- 움직임 줄이기에서는 장면의 최종 상태를 바로 표시한다. 선택 상태·기간별 데이터·키보드 이동·주소의 장면 링크를 검증한다.
- 논문의 수치를 정적 HTML에 보존한다. 도해는 구조 설명용이라고 명시하며 실제 거래별 탐지 결과로 제시하지 않는다. 원본 HWP·이메일·전문 추출본은 공개하지 않는다.
- 데스크톱과 모바일 실제 캡처로 대상 크기, 텍스트 잘림, 결과 읽기, 대비를 확인한 뒤 기존 Vercel 주소에 반영한다.

## 설계 자체의 재검토

검정+청록만 바꾸면 또 범용 AI 포트폴리오가 된다. 따라서 식별점은 색이 아니라 **하나의 A→B 거래가 관계·시간·평가 조건을 따라 달라지는 설명**으로 정했다. 실험을 하지 않은 가짜 탐지 시연은 만들지 않는다. DEUX의 연출 문법은 참고하되 로봇 자산과 다른 사이트의 그래픽은 복제하지 않는다.
