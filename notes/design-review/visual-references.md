# 시각 레퍼런스 비교와 AML 발표 웹의 적용 기준

조사일: 2026-10-09 (한국 시간)

## 조사 방법

DEUX의 공개 소스·실제 WebGL 화면을 기준으로 두고, 아래 여섯 공식 사이트를 별도 Chromium에서 1600×900으로 열어 화면과 첫 스크롤 상태를 관찰했다. 검색 결과의 소개나 과거에 알려진 디자인만 보고 판단하지 않았다. 캡처는 `site-preview/inspiration/`에 보관했다. 일부 사이트의 첫 캡처는 로딩 연출 도중이어서 스크롤 이후 캡처도 함께 확인했다.

목표는 여러 사이트의 장식을 합치는 것이 아니다. **DEUX의 발표 구조에 공간감, 초점 이동, 정보 전달의 정밀함을 보강하는 것**이다.

## 적용 우선순위

1. **DEUX의 연속된 발표 무대:** 프레임과 대상을 유지하면서 장면만 바뀐다. 이것이 사용자가 요청한 인상의 뼈대다.
2. **Igloo·Lusion의 크기와 깊이:** 무대에 작은 장식 SVG를 붙이는 대신, 가까운 노드와 먼 노드가 겹치고 대상을 확대해 프레임을 채운다.
3. **Stripe의 설명 가능한 연결:** 계좌·거래·집계가 무엇인지 실제 설명과 함께 드러낸다. 정보 전달이 없는 파티클 수를 늘리지 않는다.
4. **Linear의 결과 가독성:** 연구 결과를 보는 장에서는 효과를 줄이고 수치·조건·비교축이 먼저 읽히게 한다.
5. **Active Theory의 절제된 조명:** 청록을 전 화면에 뿌리기보다 현재 설명하는 구조에 집중한다.

## 새 구현을 판단하는 시각 명세

### 무대

배경은 순검정에 가까운 색, 기본 본문은 흰색·중간 회색, 금융 포인트는 청록으로 고정한다. 중심 거래망은 오른쪽 공간의 약 55~65% 너비를 사용한다. 주위에 사각형 경계를 두지 않는다. 본문 뒤에는 아주 약한 검정 그라데이션을 두어 시각 요소와 글의 충돌을 막는다.

전경 노드는 크고 선명하게, 후경 노드는 작고 어둡게 둔다. 연결선도 깊이에 따라 밝기가 달라야 한다. 모든 선이 같은 굵기·색이면 입체 구조가 평면 도식처럼 보인다. 화면 안의 정보 노드는 식별 가능한 수로 제한하고, 실제 데이터가 아닌 구조 설명 장면에는 그 사실을 한 곳에 표시한다.

### 장면의 전개

표지는 큰 전체망, 데이터는 한 거래의 확대, 비교 설계는 같은 거래에서 이웃 정보가 펼쳐지는 모습, 결과는 망이 뒤로 물러나며 정확한 비교 그래프가 나타나는 모습으로 연결한다. 선택한 거래와 주변 노드의 정체성이 이어져야 한다. 장면마다 무작위로 다시 뽑은 점들은 이 연속성을 만들지 못한다.

각 장에는 한국어 핵심 주장 하나를 둔다. 수식이나 모델명은 그 주장을 설명할 때만 보인다. 영어 외곽선 챕터 글자는 작게 사용하거나 생략할 수 있지만, 그 대신 중심 대상의 크기·시점 변화는 반드시 남긴다.

### 상호작용

사용자가 장을 넘기면 장면이 바로 반응하고, 약 0.7~1초 안에 초점이 정리된다. 이전 전환이 끝날 때까지 다음 조작을 막지 않는다. 모델 비교 수치는 처음부터 함께 보이게 한다. 데모 버튼은 실제로 이해가 달라지는 하나의 동작에만 사용한다.

움직임 줄이기를 선택하면 동일 장면의 최종 상태를 즉시 보여준다. 지속적인 회전·카메라 흔들림·입자 애니메이션도 함께 멈춘다. 모바일은 같은 의미의 간단한 2D 구조와 세로 본문으로 제공한다.

## 이전 수정에서 되돌릴 판단

‘불필요한 것이 많다’는 피드백을 장면을 적게 만드는 것으로만 해석한 것이 문제였다. 반복 문장은 줄이되 사용자가 원한 **크고 입체적인 설명 대상과 장면 전환**은 더 발전시켜야 한다. 4장이라는 수보다 보고서의 논리와 근거에 맞는 장면 수를 먼저 정한다.

또한 ‘가벼운 구현’은 사용자가 요구한 공간감까지 포기하는 이유가 될 수 없다. 반대로 3D 라이브러리를 설치한 사실만으로 좋은 디자인이 되지도 않는다. 실제 캡처에서 중심 대상·타이포·리듬이 제대로 보이는지를 기준으로 판단한다.

## 확인 범위와 한계

이번 비교는 각 사이트의 공식 공개 페이지와 데스크톱 렌더링에 근거한다. 모든 메뉴·프로젝트·모바일 동작을 전수 검사한 것은 아니다. Bruno Simon은 진입 장면까지 관찰했으며 전체 게임 동선의 품질을 평가하지 않았다. 사이트의 자산·문구·코드를 새 포트폴리오에 복제하지 않는다.
