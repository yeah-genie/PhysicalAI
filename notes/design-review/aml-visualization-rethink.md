# AML 시각화 재검토: 각도 변화에서 데이터 표현 변화로

작성일: 2026-10-10

## 현재 화면이 반복적으로 느껴지는 이유

현재는 26계좌·48거래의 하나의 부분망을 반복 사용한다. 구도와 밝기가 바뀌어도 구체와 연결선이라는 표현은 그대로다. 심지어 결과·분포 장에서도 희미한 거래망을 배경에 남겨 모든 장이 비슷한 인상을 준다. 계좌망인데 신경망으로 보인다는 반응도 역할을 읽게 해 주는 라벨과 배치가 약하다는 신호다.

레퍼런스의 원리는 큰 연구 대상을 설명에 맞게 조작하는 것이다. 모든 설명을 같은 형태의 3D 그래프로 밀어 넣는 규칙은 아니다. AML에서는 시간, 거래 관계, 표본 분포, 모델 평가가 각각 다른 질문이다. 표현도 질문에 따라 달라져야 한다.

## 전체 CSV에서 다시 확인한 관측

HI-Small_Trans.csv 전체 5,078,345행을 스트리밍하여 시간별 거래량·양성 라벨 수, 결제 방식별 교차 집계, 수취 통화별 집계, 같은 통화 안의 금액 규모 구간을 다시 계산했다. 전체 거래·양성 합계와 기존 집계의 일치를 assert로 확인했다.

- 전체 양성 라벨은 5,177건, 약 0.1019%다.
- ACH는 600,797거래로 전체의 11.83%지만 양성 라벨은 4,483건으로 전체 양성의 86.59%다. ACH 안의 양성률은 약 0.7462%다. 서로 다른 분모를 혼동하지 않아야 한다.
- 9월 11일부터 거래량은 수백·수십 건 단위로 급감한다. 전체 기간의 거래량 감소와 양성률 변화는 함께 보여줘야 한다. 로그 거래량 그래프만 보여주면 이 단절을 과소평가할 수 있다.
- 통화는 15개, 결제 방식은 7개다. 금액을 통화 구분 없이 합쳐 흐름의 굵기를 정하면 잘못된 그림이 된다.
- 전체 은행 간 거래는 4,387,090건이다. 이 사실만으로 의심 거래 또는 금융기관의 위험도를 주장하지 않는다.

관측은 이 합성 파일의 분포다. ACH 사용이 자금세탁의 원인이라는 결론이나 모델 성능에 대한 인과 설명은 아니다. 라벨이 0인 방식에서도 실제 세계에 위험이 없다고 해석할 수 없다.

## 추천: 시간의 격자 → 한 거래의 관계 → 시간 경계 → 평가와 분포

표지의 중심 대상은 **시간에 쌓이는 거래**로 바꾼다. 날짜×시간의 집계 격자를 크게 보여주고, 필요하면 깊이를 살짝 준 평면 또는 날짜별 층으로 연출한다. 각 칸은 거래 여러 건의 집계이며, 임의 입자를 개별 거래처럼 표현하지 않는다. 500만 건을 모두 브라우저에 그릴 필요는 없다.

관계를 설명하는 장에서만 실제 부분망을 사용한다. 이때 계좌를 구체 구름으로 두지 않고 2-hop → 1-hop → 대상 거래의 역할별 열에 배치한다. 같은 계좌 쌍의 반복 거래는 개수로 묶고 펼칠 수 있게 한다. 중심 거래를 유지하되 구조 자체가 읽히게 만든다.

시간 제한 장에서는 같은 거래들을 **계좌별 시간축**으로 옮긴다. 관측 시각의 세로선 뒤는 미래 영역이다. 점을 선택하면 원본 시각·금액·통화·방식이 나온다. 연결을 따라 특정 자금이 이동했다고 주장하지 않는다. 실제 자금 추적에는 별도 근거가 필요하다.

| 현재 장 | 추천 표현 | 사용자 조작과 의미 |
| --- | --- | --- |
| 표지 | 날짜×시간 거래 밀도 격자 | 시간대 선택 → 거래량·양성 수 확인 |
| 목차·장 구분 | 제목·번호 | 데이터 그래프 없이 발표의 리듬 유지 |
| 입력과 관계 | 역할별로 정렬한 수취 방향 부분망 | 단일 거래 → 1-hop → 2-hop; 반복 거래 묶음 펼치기 |
| 평가 원칙 | 계좌별 거래 타임라인 | 관측 시각 이후 거래를 숨기거나 비교 |
| 전체 결과 | 기존 논문의 모델 지표 차트 | 배경 거래망을 제거하고 지표·분모에 집중 |
| 동일 조사량 | 같은 길이의 기존 예산 막대 | 동일 864건 비교 유지; 장식보다 정확한 비교 |
| 기간별 해석 | 날짜별 거래량과 양성률의 정렬된 두 그래프 | 날짜 선택 → 표본 수와 비율 동시 확인 |
| 추가 데이터 분석 | 결제 방식의 전체/양성 구성비 | ACH 등의 편중 관찰; 모델 결과와 구분 |
| 결론 | 확인한 결과·한계·다음 비교 조건 | 배경 거래망을 반복하지 않고 결론에 집중 |

결제 방식 분석은 현재 원고 결과에 새 인과 주장을 넣는 방식이 아니라 원본 데이터의 탐색 결과로 명시해야 한다. 꼭 12장을 고집하기보다 분포 장의 가독성을 보고 별도 장 추가를 결정한다.

## 전환 효과

상시 회전·발광이나 매 장의 새로운 무작위 점 배치를 늘리지 않는다. 날짜의 격자에서 선택 시간 구간을 강조하고, 관계 장으로 넘어갈 때 한 사례를 명확히 선택한다. 역할별 배치는 같은 계좌 ID를 유지한다. 시간 장에서는 같은 거래 ID를 시간축으로 이동시킨다. 사례 추출이 대표 표본이 아니라는 사실도 유지한다.

3D는 표지의 데이터 무대와 관계를 펼치는 조작에 한정할 수 있다. 지표와 분포는 크고 선명한 2D 차트가 더 적합하다. 장마다 표현이 달라도 같은 서체, 여백, 청록 강조, 고정 발표 프레임이 연결감을 만든다.

## 검토용 시안

aml-visualization-study.html에서 세 표현을 직접 비교할 수 있다.

1. 전체 데이터의 날짜×시간 밀도 격자: 칸을 눌러 정확한 거래량·양성 수 확인.
2. 기존 사례의 계좌별 거래 타임라인: 미래 거래 표시 및 거래 상세 선택.
3. 전체 데이터의 결제 방식별 구성비: 전체 거래와 양성 라벨의 분포를 나란히 확인.

이 시안은 시각 방향을 확인하는 자료다. 현재 공개 AML 페이지를 교체하거나 새 분석을 논문의 실험 결과로 편입하지 않았다. 원본 CSV 전체·계좌 식별 문자열을 시안에 넣지 않았다. 전체 거래 집계와 이미 공개된 별칭 부분망만 사용했다.

## 이번 구현: 발표의 주장과 근거를 일치시키기

기존 발표의 문제는 시각 반복 외에도 결론의 초점이 흐린 점이었다. 결과에서 곧바로 기간별 AP로 넘어가면 표본 구성이 달라진 사실을 청중이 직접 읽기 어렵다. 결론도 같은 거래망으로 돌아가 구체적인 후속 검증이 시각적으로 남지 않았다.

14장으로 정리했다. 목차와 네 장 구분, 타이핑, 스크롤 스냅은 유지했다. 기존 실험 결과는 그대로 두고, 원본 전체의 날짜별 거래량/양성률과 결제 방식 구성비를 각각 한 장에 분리했다. 두 장은 ‘추가 탐색’으로 표시하여 논문의 실험 결과와 구분했다.

- 표지: 18일 × 24시간 실제 집계. 로그 밝기를 명시하고 시간 칸 선택 시 건수를 표시한다.
- 입력: 3D 거래망을 이 장에서만 사용. 이웃 깊이에 따라 열을 정렬하고 수취 방향과 대상 두 계좌를 설명한다. 반복 거래 묶음 펼치기는 이번 범위에서 제외했다.
- 시간 기준: 동일 48거래를 수신 계좌별 시각으로 표시. 미래 6거래는 기본 제외하며 비교할 때 빈 점으로 구분한다. 거래 상세에서 통화와 금액을 따로 유지한다.
- 성과: 배경 거래망을 제거하고 기존 AP와 조사량 비교에 집중한다.
- 추가 분석: 실제 날짜 분포 → 기간별 모델 AP → 결제 방식 편중 순서로 연결한다.
- 결론: 규모/예산, 반복 실행, 분포 변화 검증이라는 세 가지 질문으로 마무리한다. 후속 실험을 이미 수행한 것처럼 쓰지 않는다.

청록은 기본 데이터, 주황은 타임라인의 대상 거래 또는 차트의 양성 비율이다. 각 차트 안에 뜻과 분모를 표시한다. 차트는 키보드 방향키로 선택할 수 있으며 방향키 입력이 발표 페이지를 넘기지 않도록 처리했다. JavaScript가 없으면 동일 집계에서 만든 SVG를 표시하고, WebGL이 없으면 관계 장을 2D로 표시한다.

원본 재생성: scripts/build-aml-visualization.py가 transactions.json과 overview.json을 함께 만들며, scripts/build-aml-chart-assets.mjs가 네 정적 차트를 생성한다. 모델 성능 재실험은 이번 화면 개선의 범위가 아니다.
