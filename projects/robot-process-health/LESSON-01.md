# 첫 실습: 로봇 작업 한 번을 숫자로 읽기

학습 설명과 Codex 준비 자료다. 사용자 코드 실행/학습 완료 기록은 아니다.

로봇이 물체를 집어 옮기는 작업을 한 번 수행하면, 센서가 그동안의 움직임을 계속 기록한다. 그 한 번을 cycle(작업 한 회)이라고 부른다. 한 작업은 CSV의 한 행이 아니라 여러 시점의 행으로 이루어진다.

| 열 | 쉽게 읽는 방법 | 사용할 때 구분 |
|---|---|---|
| time | 그 작업의 시간 값 | 시작 후 상대 시간으로 비교 |
| sample | 어느 작업의 기록인지 나타내는 번호 | 학습/테스트 분할용이며 모델에 주지 않음 |
| joint_position_1 | 첫 관절의 위치 값 | 원본 단위 보존, 각도 단위는 별도 확인 |
| motor_torque_1 | 첫 모터의 토크 값 | 회전시키는 힘의 효과; 커졌다고 바로 고장이라고 할 수 없음 |
| anomaly | 데이터셋의 작업 전체 정상/이상 정답 | 모델이 만든 결과가 아니며 어느 순간부터 이상인지도 아님 |
| category, setting | 공식 이상 유형·조건 코드 | 설명/분할 자료, 모델 정답을 미리 알려주지 않음 |

정상 작업 755번의 첫 행은 time=0, 위치 약 -0.34142, 모터 토크 약 5.81948이다. 이상 작업 0번의 첫 행은 위치 약 -0.34146, 모터 토크 약 8.80960이다. 한 시점에서 위치 값은 가깝지만 모터 토크는 다르다. 이것만으로 판별 규칙을 정하지 않는다.

## 직접 해볼 작은 코드

저장소 루트에서 Python으로 실행한다. 오늘은 표를 읽는 이 코드만 이해하면 된다.

```python
import csv

with open('projects/robot-process-health/data/sample.csv', encoding='utf-8') as file:
    rows = list(csv.DictReader(file))

normal = next(row for row in rows if row['sample'] == '755')
print(normal)
```

CSV는 표 형태의 파일이다. `DictReader`는 각 행을 열 이름으로 읽게 해준다. `normal['time']`처럼 특정 값을 꺼낼 수 있다. 이 단계의 값은 문자열이며 계산할 때는 `float(normal['motor_torque_1'])`처럼 숫자로 바꾼다.

그다음 [센서 그림](reports/sample-signals.png)을 본다. 위는 위치, 아래는 모터 토크, 가로축은 작업 시작 후 시간이다. 정상과 이상 모두 움직일 때 토크가 바뀐다. 따라서 값의 크기와 함께 작업 단계·조건·반복 작업의 차이를 살펴봐야 한다. 지금의 두 작업은 다른 조건의 관찰 예제이며 통제된 원인 검증이 아니다.

오늘 확인할 것은 한 행과 한 작업의 차이, 위치와 토크의 차이다. 이후 충분한 기록에서 기준 방법을 만들고 오탐/미탐을 평가한다.
