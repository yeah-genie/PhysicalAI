# 팬 이상탐지 관련 문헌과 차별화할 실험

확인일: 2026-10-13. 원문·공식 과제 자료를 확인한 문헌 조사다. 아래 실험은 제안이며 모델 성능을 새로 검증한 결과가 아니다. 현재 받은 팬 음원 12개는 입문 표본이다.

## 데이터와 평가를 이해할 논문

### 1. MIMII DG — Dohi et al., DCASE Workshop 2022

[원문](https://arxiv.org/pdf/2205.13879), 특히 2절과 표 1.

핵심은 정상 소리 자체가 운전·녹음 환경 변화로 달라지는 문제다. 다섯 종류 기계에 서로 다른 domain shift 시나리오를 만들고 정상 학습 자료로 이상을 탐지한다. 기계 소리와 공장 소음을 섞는 기록 방식도 설명한다. 팬은 날개 손상·불균형·막힘·과전압을 포함한다.

우리에게는 ‘무엇을 정상의 변화로 취급할 것인가’를 정하는 출발점이다. 다만 2022 데이터의 여러 section과 2025 fan section 00의 A~E 조건 코드를 동일시하지 않는다. 실험실 기반 벤치마크 결과를 현장의 연속 열화·고장 예측으로 옮길 근거도 별도로 필요하다.

### 2. DCASE 2025 Task 2 설명 — Nishida et al., 2025

[원문](https://arxiv.org/pdf/2506.10097), 2~3절.

정상 소리로 새 기계에 대응하는 first-shot 평가를 정의한다. source 정상 990개와 target 정상 10개, 추가 소음/깨끗한 소리, 서로 다른 기계 유형의 평가가 핵심이다. AUC와 FPR 0~0.1 영역의 pAUC를 함께 평가한다. 개발 자료와 최종 평가 자료의 역할도 구분한다.

팬 한 종류의 성능을 얻었다고 전체 first-shot 일반화를 검증한 것이 아니다. 원본 과제의 domain별 AUC는 해당 domain의 정상과 section의 이상 자료를 사용하는 규칙이 있으므로, 양쪽을 모두 domain별로 나눈 자체 AUC와 구분해야 한다. 공식 evaluator의 버전을 고정하고 개인 분석 지표는 별도 열에 둔다.

## 기준 모델과 점수 보정

### 3. First-shot anomaly sound detection… — Harada et al., EUSIPCO 2023

[학회 원문](https://eurasip.org/Proceedings/Eusipco/Eusipco2023/pdfs/0000191.pdf), [arXiv](https://arxiv.org/abs/2303.00455), 3절.

정상 log-mel 입력을 재구성하는 Autoencoder와 재구성 오차 기반 점수를 사용한다. Selective Mahalanobis는 source/target의 정상 재구성 잔차 공분산을 이용하고 두 거리 중 작은 값을 선택한다. 단순 AE와 같은 학습 구조에서도 점수 계산의 선택이 중요하다는 기준이다.

우리는 신호 특징 기준 모델 이후 공식 AE와 두 점수 모드를 재현한다. 논문이 주는 것은 기준 비교이지, 현재 데이터의 성능이나 오탐률 보장이 아니다. 대상 기계의 테스트 이상 라벨로 하이퍼파라미터를 계속 고르면 first-shot 주장과 맞지 않는다.

### 4. GenRep for First-Shot… — Saengthong & Shinozaki, DCASE 2025 기술보고서

[원문](https://dcase.community/documents/challenge2025/technical_reports/DCASE2025_Saengthong_18_t2.pdf), 2절과 실험 표.

고정한 사전학습 음향 표현과 kNN을 사용하고, 전역/도메인별 Z-score와 밀도 기반 보정을 비교한다. 테스트 분포를 미리 이용하는 기존 보정 방식의 제약을 짚고 정상 학습 자료를 이용하는 대안을 탐색한다. 보고된 비교에는 모델 크기와 앙상블도 포함된다.

따라서 ‘사전학습 모델 + kNN + 정상 자료로 보정’만으로 새 방법이라고 말하기 어렵다. 재학습 비용을 줄인 비교 후보로 삼되, 어떤 통계가 학습·검증·테스트에서 계산됐는지 구현과 표를 대조해야 한다. 기술보고서의 성능을 우리가 재현한 것으로 표기하지 않는다.

### 5. Robust Train-Normal Calibration… — Zhang & Li, DCASE 2026 기술보고서

[원문](https://dcase.community/documents/challenge2026/technical_reports/DCASE2026_Zhang_11_t2.pdf), 4~5절.

정상 점수의 높은 꼬리와 target 오탐에 초점을 둔 보정·guard를 보고한다. 더 많은 표현이나 다른 보정이 일부 AUC를 개선하면서 낮은 FPR 구간 성능을 악화시킨 실패 사례도 기술한다. 개발 세트 선택이 낙관적일 수 있다는 한계와 최종 평가 전 고정 절차를 명시한다.

우리가 참고할 점은 개선된 평균과 악화된 조건을 같이 남기는 실험 태도다. 이는 2026 두 채널 과제의 제출 기술보고서이며 독립 재현·동료심사를 확인한 결과가 아니다. 보고서가 이미 보정과 오탐 강건성을 다루므로 그 주제 자체의 최초성을 주장하지 않는다.

## 차별화 제안: 적은 정상 자료에서 경보를 얼마나 믿을 수 있는가

취업 포트폴리오의 차별화와 논문 방법의 신규성은 구분한다. 당장은 한 질문을 재현 가능한 실험으로 완결하는 것이 목표다.

> 같은 탐지 모델에서, 정상 자료의 수와 환경 조건이 바뀌면 고정 임곗값의 오탐·미탐과 경보 수는 얼마나 흔들리는가?

### 첫 비교의 범위

1. 충분한 저장 공간을 확보하고 전체 공식 fan 자료를 검사한다. 12개로 기준 성능을 주장하지 않는다.
2. source 정상 990개를 조건별로 fit 792개, calibration 198개로 분리한다. 기록 단위·seed·원본 파일 ID를 저장하며 같은 파일의 시간 창은 같은 분할에 둔다. 실제 원 녹음 공유를 식별할 정보가 있으면 그것을 우선 그룹 기준으로 사용한다.
3. 첫 비교에서는 탐지 모델과 특징을 고정한다. target 정상은 encoder 학습에 쓰지 않고 별도 정상 reference로 사용한다. 가용 reference 0/2/5개 시나리오와 선택 seed를 반복한다. 같은 파일을 fit와 calibration에 중복 사용하지 않는다.
4. source calibration의 경험적 분위수 임곗값을 기준으로 하고, target reference 추가 또는 보수적인 전역 임곗값 조정과 비교한다. 추론에서 source/target 정답이나 normal/anomaly 파일명은 주지 않는다. 변경 방법·혼합 비율은 테스트를 보기 전에 고정한다.
5. 모델 순위 평가(AUC/pAUC)와 고정 임곗값의 실제 판단(FPR/TPR/경보 수)을 나누어 보고한다. 전역 단조 점수 변환만으로는 순위가 바뀌지 않으므로 AUC 개선을 기대하거나 주장하지 않는다.
6. 조건 A~E별 정상 경보율과 반복별 변동을 모두 남긴다. 테스트 라벨은 마지막 평가에만 사용하고, 최상의 seed만 뽑지 않는다. fan 평가 뒤 방법을 고정하고 다른 기계에서 다시 확인한다.

이 단계는 낮은 오탐 구간을 비교하는 평가 프로젝트다. 정상 reference가 2~5개일 때 특정 오탐률을 보장하지 않는다. conformal 등 보장형 방법을 나중에 추가하면 필요한 교환가능성·독립성 가정을 명시하고 domain shift에서의 실패도 평가한다.

### 적은 표본이 만드는 한계

target 정상 테스트는 50개이므로 오탐 한 건이 2%다. 0건이어도 실제 오탐률 1% 이하를 입증했다고 할 수 없다. 독립적이고 같은 분포의 Bernoulli 표본이라는 가정에서 0/50의 단측 95% 이항 상한은 `1 - 0.05^(1/50)` ≈ 5.82%다. 같은 가정에서 그 상한을 1% 이하로 하려면 오탐 0건인 정상 표본이 최소 299개 필요하다. 이는 직접 계산한 예시이며 이 데이터가 그 독립성 가정을 충족한다고 주장하지 않는다. 시간 창을 잘라 표본 수만 부풀리는 것은 해결책이 아니다.

공식 pAUC의 FPR≤10% 영역과 우리가 관심 있는 1% 운영 목표도 같은 지표가 아니다. 균형 잡힌 테스트 precision을 현장의 희귀 이상 발생률로 옮기거나 실제 경보/시간으로 환산하지 않는다.

### 최종 결과물과 확장

첫 결과물은 고정된 분할/설정, 실행 명령, clip별 점수 CSV, 조건별 평가표, 정상 오탐 사례, 개선/악화된 결과, 제한을 포함한다. 웹 데모에서는 저장된 결과를 재생하고 오탐·미탐을 설명한다. 임의로 이어 붙인 클립은 실제 공장의 연속 수명 기록이라고 표시하지 않는다.

다음 단계는 고정 음향 encoder+kNN 비교, 다른 기계로의 일반화, 2026 가까운/먼 채널 비교다. 학습 비용·추론 지연·메모리도 동일 장비와 조건에서 측정한다. LeRobot 작업 실패와 설비 물리적 고장은 별도 실험으로 유지한다.

새 알고리즘 또는 연구 논문을 목표로 할 때는 추가 선행연구 조사와 다중 데이터/기계 검증이 필요하다. 현재는 위 실험의 효과나 학술적 신규성이 확인되지 않았다.
