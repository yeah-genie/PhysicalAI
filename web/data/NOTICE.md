# 거래 부분망 데이터

출처: IBM AMLworld / Altman et al. (2023), https://github.com/IBM/AML-Data
원본: HI-Small_Trans.csv (사용자가 제공한 합성 거래 데이터)
데이터 라이선스: CDLA-Sharing-1.0. 전문: LICENSE-CDLA-Sharing-1.0.txt
이 부분집합과 파생 데이터도 CDLA-Sharing-1.0으로 제공한다.

변경 사항: 설명용 부분망 추출, 은행+계좌 조합을 A001 등의 별칭으로 치환,
원본 데이터 행 번호와 hop/phase 추가. 금액·통화·시각·라벨은 원본값이다.
원본 전체 파일과 실제 계좌 식별 문자열은 배포하지 않는다.

2022-09-09의 양성 비자기거래 후보 앞 128건에서 과거 2-hop 연결을 수집하고,
연결 계좌가 많은 사례를 선택했다. 계좌별 최근 유입 최대 8건을 사용한다.
대표 표본이나 모델 학습 샘플이 아니며, 26계좌·48거래는 설명을 위한 선택이다.
미래 연결은 비교용으로 포함했으며 모델 입력에 사용했다는 의미가 아니다.
CSV 라벨은 거래의 정답 라벨이며 계좌의 범죄 여부 또는 모델 예측이 아니다.

거래 ID의 숫자는 헤더를 제외한 1부터 시작하는 원본 데이터 행 번호이다.
전체 요약, 추출 기준, 원본 SHA-256은 transactions.json에 기록했다.
추출 스크립트: 저장소 scripts/build-aml-visualization.py
