01 / 문제

거래 관계를 더하면
자금세탁 탐지가 달라질까?

IBM 합성 거래 데이터에 네 모델을 적용하고,
탐지 성능과 경보 수의 차이를 비교한 딥러닝 과제입니다.

이번 과제에서 한 일

  • 공통 거래 특징 45개를 구성하고, 날짜순으로 학습·검증·테스트 분할
  • XGBoost · Edge-MLP · GIN · PNA의 단일 실행 결과 비교
  • 모델별 경보 수가 달라, 같은 864건을 조사하는 조건에서도 재비교

IBM AML HI-Small · 전체 5,078,345건 중 자금세탁 라벨 5,177건 (약 0.10%)

02 / 비교 설계

모델을 고른 기준은
사용하는 정보와 처리 방식입니다.

XGBoost ↔ Edge-MLP
같은 거래 특징에서 트리 모델과 신경망을 비교합니다. XGBoost는 딥러닝의 효과를 판단할 기준선입니다.
Edge-MLP ↔ GIN · PNA
거래 특징에 주변 계좌·거래 관계를 더했을 때의 차이를 봅니다.
GIN ↔ PNA
합계 중심 집계와 여러 통계량을 사용하는 집계를 비교합니다. 모델 크기와 학습 예산의 차이도 함께 해석합니다.

04 / 배운 점

전체 점수만으로는
비교가 끝나지 않았습니다.

경보 수가 달랐습니다.
모델별 기준으로 선택된 거래 수가 달라, 상위 864건으로 조사량을 맞춰 한 번 더 비교했습니다.
날짜별 결과도 달랐습니다.
테스트 후반에는 모델 순서가 바뀌었습니다. 전체 평균과 날짜별 데이터 분포를 함께 봐야 했습니다.
집계 방식만 바뀐 게 아니었습니다.
PNA는 GIN보다 파라미터가 약 4.4배 많았습니다. 다음에는 학습 예산을 맞추고 여러 시드에서 결과를 확인할 계획입니다.

현재 근거는 합성 데이터의 단일 실행 결과입니다.
