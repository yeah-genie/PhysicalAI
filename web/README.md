# Signals & Systems

공개 사이트: https://yejin-signals-systems.vercel.app/

나예진의 학습 기록을 읽는 정적 포트폴리오다. 별도 프레임워크·빌드·서버 API 없이 HTML/CSS/JavaScript로 제공한다.

- `index.html`: AML 실험과 로봇 학습으로 들어가는 입구
- `aml.html`: 표지·목차, 연구 설계·1차 성과·추가 분석·다음 단계의 4개 구분 장과 6개 내용 장, 총 12장
- `robotics.html`: 공부한 내용 → 각도와 자세 → 다음 공부, 3장

## 내용과 근거

AML은 사용자가 제공한 `[2026-09-30] ACK 2026_나예진.hwp` 연구 원고의 설정·수치·해석을 바탕으로 한다. 새로 모델을 학습하거나 개인별 기여를 추정하지 않았다. 전체 AP와 임곗값 경보 수, 동일 예산 864건의 탐지 수, 날짜별 AP를 구분해 표시한다. 기간 버튼은 실제 논문에 있는 두 기간의 집계만 전환한다. 원본 문서와 이메일을 포함한 전문 추출본은 배포·커밋 대상에서 제외한다.

Three.js 거래망은 사용자의 `HI-Small_Trans.csv`에서 추출한 **실제 합성 거래 부분망(26계좌·48거래)**이다. `scripts/build-aml-visualization.py`가 원본 전체를 스트리밍 검증하고 `data/transactions.json`을 만든다. 데이터는 CDLA-Sharing-1.0이며 출처·변경사항·표본 선택 편향은 `data/NOTICE.md`에 기록했다. CSV 전체는 공개하지 않는다. 시각화는 최근 이웃 최대 8건을 사용한 설명용 부분 추출이며, 학습의 층별 최대 10개 샘플링이나 모델 예측 결과와 구분한다.

동일한 A001→A002를 유지하며 전체/한 거래, 과거 0·1·2-hop, 미래 연결 비교, 송금 방향 재생을 조작한다. 드래그 회전·Shift+휠 확대·더블클릭 복원도 지원한다. 노드 색으로 계좌의 범죄 여부나 개별 예측을 표현하지 않는다. 장면 모듈은 `aml-scene.js`, 순수 선택·배치 함수는 `aml-graph.js`, AML 전용 스타일은 `aml.css`에 있다. Three.js 0.186.1과 SUIT Variable은 `vendor/`에 라이선스와 함께 보관한다.

로봇 내용은 `notes/2026-10-07-modern-robotics.md`의 실제 질문과 수정 과정을 바탕으로 한다. 데모는 이 사이트에서 만든 이상적 평면 2R 기구학이다. 링크 길이는 각각 1, 두 번째 관절각은 첫 링크에 대한 상대각이다. 하나의 각도 입력이 로봇 자세와 C-space 좌표를 함께 갱신한다. 관절 제한·충돌·동역학은 포함하지 않는다. 설명의 공식 근거와 상세 학습 기록은 페이지에서 연결한다.

## 화면과 접근성

AML은 사용자의 2026-10-09 지시에 따라 모든 창에서 1280×720 발표 구도를 비례 축소한다. 세로 휴대폰에서도 문서형으로 바뀌지 않으며, 가로 화면에서 더 크게 볼 수 있다. 로봇의 기존 반응형 동작은 유지한다. WebGL 실패 시 동일 데이터의 SVG가 버튼에 반응한다. JavaScript가 없으면 본문과 미리 생성한 정적 SVG를 제공한다.

스크롤·클릭 가능한 목차·장 구분 페이지의 내용 보기·이전/다음·방향키로 이동한다. `aml-presentation.js`가 AML 제목의 타이핑을 담당한다. 글자 자리를 미리 확보해 구도를 유지하고, 장 전환으로 중단하거나 움직임 줄이기를 켜면 원문을 즉시 복원한다. 제목의 전체 내용은 접근성 이름으로 유지한다. 장별 해시 링크도 지원한다. 시스템의 움직임 줄이기 설정과 화면 버튼을 지원한다. 3D는 장면 전환·직접 조작·요청한 방향 재생 때만 렌더링하며 자동 회전하지 않는다. AML 본문과 표는 JavaScript가 없어도 읽을 수 있고 후반 기간 수치도 noscript로 제공한다.

## 실행과 검증

이 폴더에서 `python -m http.server 8000`을 실행한다.

- `node web/test.js` (저장소 루트): 논문 수치와 예산 막대 비율, 12장 순서, 2R 길이·주기성, 내부 링크
- `node site-check.cjs` (저장소 루트): Chrome/Playwright에서 6개 화면 크기, 장의 잘림, 3D 렌더링·장면 변화, AML 고정 비율, 기간별 값, 2R, 키보드·앵커·움직임 설정, JavaScript/WebGL 미지원 표시 확인
- `node web/aml-test.js`: 부분망 무결성·시간 제한·범위 선택·원본 집계 확인
- `node aml-check.cjs`: AML 새 인터랙션·3개 뷰포트의 잘림·WebGL 대체 화면·로봇 조작 회귀 확인 (기본 포트 8001)
- `SITE_URL` 환경 변수를 지정하면 같은 검사를 공개 주소에서 실행한다.

Vercel 프로젝트는 `yejin-signals-systems`, 저장소는 `yeah-genie/PhysicalAI`다. Root Directory는 `web`, Framework는 Other, Build Command는 없음, Output Directory는 `.`이다. 연결된 master 브랜치에 push하면 자동 배포된다. 환경 파일과 `.vercel`은 커밋하지 않는다.
